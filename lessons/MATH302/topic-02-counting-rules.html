2. Fundamental Counting Principle

Counting problems can be approached systematically using several formal techniques:

📋 Systematic Counting Methods

  • Systematic Listing: A method to count the number of possible outcomes by methodically listing all of them. This method ensures that no outcome is missed or repeated, especially when the choices are few and easy to handle manually.
  • Tabular Method: A technique used to count the total number of possible outcomes by organizing them into a table, typically using rows and columns.
  • Tree Diagram: A visual representation used to systematically list all possible outcomes of a counting problem by branching out choices step by step. Offers a visual and structured way to display all possible outcomes, especially helpful for multi-stage problems where choices unfold step by step.
Fundamental Counting Principle (FCP): If one event has $m$ possible outcomes and the second event has $n$ possible outcomes, then the sequence of events has $m \times n$ possible outcomes. $$\text{Total Outcomes} = n_1 \times n_2 \times n_3 \times \dots \times n_k$$

3. Factorials ($n!$)

When arranging objects in sequence without repetition, we utilize factorials.

Factorial Definition: The factorial of a positive integer $n$, denoted by $n!$, is the product of all positive integers less than or equal to $n$. Additionally, the factorial of 0 is defined as 1. $$n! = n \times (n-1) \times (n-2) \times \dots \times 2 \times 1 \quad \text{and} \quad 0! = 1$$

4. Permutations (Order Matters)

When selecting and arranging items where position or sequence creates distinct outcomes, we use permutations.

Permutation Definition: A permutation is an arrangement of objects in a specific order.

Let $n$ be a positive integer and $1 \le r \le n$. A permutation of $n$ objects taken $r$ at a time is a permutation of $r$ objects selected from $n$ distinct objects. $$P(n, r) = \frac{n!}{(n-r)!}$$

5. Circular Permutations

This leads us to the concept of circular permutations, where the focus is on how objects are arranged relative to one another rather than their absolute position.

Standard Circular Permutation: The number of ways to arrange $n$ distinct objects in a circle without a fixed reference point is: $$P_{\text{circular}} = (n-1)!$$

⚠️ Words of Caution!

  1. Fixed Reference Point: If a circular arrangement has a fixed reference point, the problem is treated as a linear permutation rather than a circular one, since the reference point removes the rotational symmetry. $$\text{Ways} = n!$$
  2. Reflectional Symmetry (Flippable Objects): If the circular object can be flipped/reflected along an axis, such as bracelets or keychains, the number of permutations of $n$ distinct objects in a circle should also be divided by 2 to account for the reflection. $$\text{Ways} = \frac{(n-1)!}{2}$$

6. Combinations (Order Does NOT Matter)

When selecting items where sequence does not change the result, we use combinations.

Combination Definition: Let $n$ be a positive integer and $1 \le r \le n$. A combination of $n$ distinct objects taken $r$ at a time is a combination of $r$ objects selected from $n$ distinct objects.

The number of combinations of $n$ objects taken $r$ at a time is denoted by $C_r^n$ or $C(n,r)$: $$C(n, r) = \binom{n}{r} = \frac{n!}{r!(n-r)!}$$

C(6, 3) = 120 / 3! = 20 unique blends
A committee of 3 students needs to be chosen from a group of 5 candidates. How many unique committee teams can be formed?

7. Permutation vs. Combination

When solving any counting problem, ask one core question: Does order create a distinct outcome?

  • ORDER MATTERS (Permutation $P(n,r)$): PIN codes, race ranks, assigned officer roles (Pres/VP).
  • ORDER DOES NOT MATTER (Combination $C(n,r)$): Pizza toppings, committee teams, flavor blends.
🧠 Symmetry Property: Without computing, why is $\binom{100}{98}$ exactly equal to $\binom{100}{2}$?

Level 1: Built-in Factorials, P(n,r), and C(n,r) 
import math

n = 6
r = 3

# Factorial n!
print(f"{n}! = {math.factorial(n)}")

# Linear Permutation P(6, 3)
perm = math.perm(n, r)
print(f"P({n}, {r}) = {perm}")

# Combination C(6, 3)
comb = math.comb(n, r)
print(f"C({n}, {r}) = {comb}")
Level 2: Generating & Printing Actual Systematic Lists 
import itertools

items = ['Sweet', 'Sour', 'Salty']

# Print all ordered Permutations of 2 items
print("--- PERMUTATIONS (Order Matters) ---")
for p in itertools.permutations(items, 2):
    print(p)

# Print all unordered Combinations of 2 items
print("\n--- COMBINATIONS (Order Does Not Matter) ---")
for c in itertools.combinations(items, 2):
    print(c)
Level 3: Resolving Susruta's 63 Remedy Blends via Loop 
import math

total_tastes = 6
total_remedies = 0

# Sum C(6, r) for r from 1 to 6
for r in range(1, total_tastes + 1):
    ways = math.comb(total_tastes, r)
    print(f"Blends with {r} taste(s): {ways}")
    total_remedies += ways

print("-" * 30)
print(f"Total Susruta Remedies = {total_remedies}")
