1. Economic Models, Variables & Equations

Lecturer: William Angelo V. Gonzales

🎯 Intended Learning Outcomes:

  • Apply the real-number system and set theory to economic modeling.
  • Plot points and identify quadrants on the Cartesian coordinate plane ($\mathbb{R}^2$).
  • Differentiate relations from functions and determine domains, ranges, and types of economic functions.

An economic model is an abstract, simplified description of reality designed to yield testable hypotheses about economic behavior.

Variables, Constants, and Parameters:
  • Variable: A magnitude whose value changes (e.g., Price $P$, Profit $\pi$, Revenue $R$, Cost $C$, Income $Y$, Savings $S$, Investment $I$).
  • Constant: A fixed numerical value (e.g., $7, 10, -6$). In $7P$, $7$ is the coefficient.
  • Parameter: A parametric constant representing a general case (e.g., $aP$). Usually denoted by $a, b, c$ or Greek letters $\alpha, \beta, \gamma$.
Three Types of Economic Equations:
  1. Definitional Equation (Identity): Expresses identical meaning ($\equiv$ or $=$).
    Example: Profit identity $\pi \equiv R - C$.
  2. Behavioral Equation: Models how a variable responds to changes in other variables.
    Examples: $C = 75 + 10Q$ or $C = 110 + Q^2$.
  3. Conditional Equation: States an equilibrium requirement to be satisfied.
    Examples: $Q_d = Q_s$ (Market Clearing) or $S = I$ (Savings = Investment).

3. The Real-Number System

Mathematical modeling relies on the Real-Number System $\mathbb{R}$, which corresponds to points along the continuous real number line:

  • Natural Numbers ($\mathbb{N}$): $\{1, 2, 3, 4, 5, \dots\}$
  • Integers ($\mathbb{Z}$): $\{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}$
  • Rational Numbers ($\mathbb{Q}$): $\{ \frac{a}{b} \mid a, b \in \mathbb{Z}, b \neq 0 \}$ (e.g., $\frac{1}{2}, -\frac{7}{5}, \frac{22}{7}, 1.125, 2.3333\dots$)
  • Irrational Numbers ($\mathbb{J}$): Non-repeating, non-terminating decimals (e.g., $\sqrt{2}, \sqrt{5}, \pi$).
  • Real Numbers ($\mathbb{R}$): Union of rational and irrational numbers ($\mathbb{R} = \mathbb{Q} \cup \mathbb{J}$).

4. Concept of Sets, Cardinality & Set Operations

A set is a well-defined collection of distinct objects. Order and repetition do not change the set: $\{c, a, t, a, n, d, u, a, n, e, s\} = \{c, a, t, n, d, u, e, s\}$.

Types of Sets & Cardinality $|A|$:
  • Cardinality ($|A|$): The number of elements in set $A$.
  • Singleton Set: Set containing only 1 element ($|M| = 1$).
  • Empty / Null Set ($\emptyset$ or $\{\}$): Set containing no elements ($|N| = 0$).
  • Power Set $\mathcal{P}(A)$: Set of all subsets of $A$. $|\mathcal{P}(A)| = 2^{|A|}$.
    Example: If $A = \{a, b\}$, then $\mathcal{P}(A) = \{\emptyset, \{a\}, \{b\}, \{a, b\}\}$, so $|\mathcal{P}(A)| = 2^2 = 4$.

5. Cartesian Coordinate Plane ($\mathbb{R}^2$)

The Cartesian coordinate plane ($\mathbb{R}^2 = \mathbb{R} \times \mathbb{R}$) is formed by two perpendicular real number lines intersecting at the origin $(0, 0)$. Elements in $\mathbb{R}^2$ are ordered pairs $(x, y)$, where order matters: $(3, 5) \neq (5, 3)$.

Four Quadrants:
  • Quadrant I: $x > 0, y > 0$
  • Quadrant II: $x < 0, y > 0$
  • Quadrant III: $x < 0, y < 0$
  • Quadrant IV: $x > 0, y < 0$

6. Relations and Functions

A relation is a correspondence or relationship between two sets, composed of ordered pairs.

Examples ($A = \{3, 4, 6, 8\}$, $B = \{4, 5, 7, 9\}$):
  • $r_1 : A \to B = \{(3, 7), (3, 9), (4, 5), (6, 7), (8, 9), (8, 5)\}$
  • $r_2 : A \to B = \{(3, 5), (4, 5), (6, 4), (8, 7)\}$

A function is a relation in which each $x$-element has only one $y$-element associated with it (no repeated $x$-values).

  • $r_1$ is NOT a function because $x = 3$ and $x = 8$ map to multiple $y$-values.
  • $r_2$ **IS a function** because every $x$-value is unique.
Functional Notation $y = f(x)$, Domain & Range:
  • Independent Variable: $x$ | Dependent Variable: $y$
  • Domain: Set of permissible values for $x$.
  • Range: Set of images $y$ mapped from $x$.
Firm Capacity Example: Daily total cost $C = 150 + 7Q$ with daily output capacity limit of $100$ units ($0 \le Q \le 100$).
  • Domain: $\{Q \mid 0 \le Q \le 100\}$
  • Range: $\{C \mid 150 \le C \le 850\}$

7. Types of Functions

  • Constant Function: $f(x) = k$. Graph is a horizontal line (e.g., $f(x) = 30$ on $10 \le x \le 70$).
  • Polynomial Function: $f(x) = a_0 + a_1 x + a_2 x^2 + \dots + a_n x^n$.
    • Degree 1 = Linear Function: $f(x) = 15 - 0.5x$
    • Degree 2 = Quadratic Function: $f(x) = -2.5 - x + 0.1x^2$
    • Degree 3 = Cubic Function
  • Rational Function: $f(x) = \frac{p(x)}{q(x)}$ where $q(x) \neq 0$ (e.g., $f(x) = \frac{3x}{x - 2}$ on $\mathbb{R} \setminus \{2\}$).
  • Exponential Function: $f(x) = b^x$ (e.g., $f(x) = 2^x$ for $x \ge 0$).
  • Trigonometric Function: Involves $\sin x, \cos x, \tan x$ (e.g., $f(x) = \cos x$).
Quick Check: What is the domain restriction for $f(x) = \frac{3x}{x - 2}$?

8. Functions of Two or More Independent Variables ($\mathbb{R}^3$)

Economic models often involve functions with two or more independent variables:

$$z = f(x, y)$$ Here, $x$ and $y$ are independent variables, and $z$ is the dependent variable. Graphing requires a 3-dimensional coordinate system ($\mathbb{R}^3$).

Example: Production/surface function $f(x, y) = x^2 + 2xy + y^2 = (x + y)^2$.

def capacity_cost_function(Q):
    if not (0 <= Q <= 100):
        raise ValueError("Q out of valid domain [0, 100]")
    return 150 + 7 * Q
