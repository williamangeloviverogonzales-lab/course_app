1. Static Market Equilibrium in Matrix Form

In economic models, static market equilibrium occurs when quantity demanded ($Q_d$) equals quantity supplied ($Q_s$):

$$\begin{aligned} Q_d &= a - bP \quad (a, b > 0) \\ Q_s &= -c + dP \quad (c, d > 0) \end{aligned}$$ Setting $Q_d = Q_s = Q^*$ yields the linear system: $$\begin{pmatrix} 1 & b \\ 1 & -d \end{pmatrix} \begin{pmatrix} Q^* \\ P^* \end{pmatrix} = \begin{pmatrix} a \\ -c \end{pmatrix}$$
Quick Check: What is the equilibrium price formula ($P^*$) obtained by setting $a - bP = -c + dP$?

🐍 Python Implementation (NumPy Matrix Solver)

import numpy as np

# System: A * [Q, P] = B
# [ 1   2 ] [Q]   [100]
# [ 1  -3 ] [P] = [-20]
A = np.array([[1, 2], [1, -3]])
B = np.array([100, -20])

solution = np.linalg.solve(A, B)
print(f"Equilibrium Q*: {solution[0]:.2f}")
print(f"Equilibrium P*: {solution[1]:.2f}")
